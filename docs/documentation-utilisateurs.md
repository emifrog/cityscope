La présentation couvre la finalité, les fonctions, les responsabilités, la protection des données,
l’exploitation, l’état de réalisation et la préparation du pilote. Le guide décrit les menus et
parcours utilisateurs, les résultats attendus, le dépannage et un exercice complet sur données fictives.

Les documents distinguent les fonctions livrées des qualifications restantes. L’adresse de connexion,
les comptes, les coordonnées du support et les consignes locales sont fournis par le SIS ; aucun secret
ni compte de démonstration n’est intégré aux versions diffusables.

Pour maintenir cette documentation, faire évoluer les sources Markdown avec les parcours du produit,
mettre à jour la date et la version documentaire, puis actualiser les versions Word et PDF en contrôlant
les sommaires, la pagination et les tableaux. Conserver la cohérence des trois formats d’un même document.
